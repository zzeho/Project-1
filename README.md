# Project-1

Installation Guide

1. Clone the repository

´´´
git clone https://github.com/zzeho/Project-1.git
cd Project-1

´´´

2. Create a virtual environment

´´´
python3 -m venv venv
source venv/bin/activate
´´´

3. Install Django

´´´
pip install django
´´´

4. Database migrations

´´´
python3 manage.py migrate
´´´

5. Run server

´´´
python3 manage.py runserver
´´´
